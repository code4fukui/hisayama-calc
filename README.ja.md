# hisayama-calc

久山町スコアに基づいて、心血管疾患の10年間の発症リスクを推定するウェブベースの計算ツールです。

## デモ

[https://code4fukui.github.io/hisayama-calc/](https://code4fukui.github.io/hisayama-calc/)

## スクリーンショット

ユーザーインターフェースは、健康指標を入力するためのシンプルなフォームで構成されています。フォームの下部にある結果セクションでは、総合リスクスコアと年齢層別のリスクパーセンテージが自動的に表示されます。

![hisayama-calcインターフェースのスクリーンショット。性別や血圧などの入力フィールドと、その下に色分けされたリスク結果が表示されています。](https://user-images.githubusercontent.com/5935342/220490729-39908480-77a8-4222-9572-8703055728a5.png)

## 機能

- **リスク因子入力**: 以下の6つの主要な健康指標を基にリスクを計算します:
  - 性別（男性/女性）
  - 収縮期血圧（mmHg）
  - 糖代謝異常（あり/なし）
  - 血清LDL-C（mg/dL）
  - 血清HDL-C（mg/dL）
  - 喫煙（あり/なし）
- **ポイントベースのスコアリング**: 入力値を累積ポイントスコアに変換し、ルックアップテーブルからリスクパーセンテージを算出します。
- **年齢層別の結果表示**: 40-49歳、50-59歳、60-69歳、70-79歳の4つの年齢層ごとに、10年間の心血管疾患リスクをパーセンテージで表示します。
- **色分けされたリスクレベル**: 結果を自動的にハイライト表示し、リスクの深刻さを示します:
  - **低リスク**: 薄い青色の背景
  - **中リスク**: 薄い黄色の背景
  - **高リスク**: 薄い赤色の背景

## 使い方

1.  [デモアプリケーション](https://code4fukui.github.io/hisayama-calc/)をウェブブラウザで開きます。
2.  ラジオボタンと数値フィールドを使用して、必要な健康データをフォームに入力します。
3.  データを入力すると、リスクスコアとパーセンテージが自動的に更新されます。
